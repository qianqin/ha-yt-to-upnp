# YouTube to UPnP

Cast from YouTube Music to a Teufel Raumfeld room: a DIAL cast receiver plays
into MPD, and an adapter makes the room play MPD's HTTP stream via UPnP.

A local app: build the folder with `scripts/build-ha-app.sh` from this
repository and copy it into the Home Assistant host's `/addons` share. See
[DOCS.md](DOCS.md) for setup and options.
