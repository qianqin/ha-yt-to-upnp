# YouTube to UPnP

Cast from YouTube Music to a Teufel Raumfeld room: a DIAL cast receiver plays
into MPD, and an adapter makes the room play MPD's HTTP stream via UPnP.

Add `https://github.com/qianqin/ha-yt-to-upnp` under Settings → Apps →
Repositories and install the app; Home Assistant builds it on the host
from prebuilt programs of the GitHub release (checked by SHA-256, nothing is
compiled). See [DOCS.md](DOCS.md) for installation, setup and options.
